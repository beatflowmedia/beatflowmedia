# Design Tokens

Design tokens are the foundational elements of the BeatFlowMedia design system. They provide a consistent visual language across all components and ensure brand consistency.

## Spacing

Our spacing system uses a consistent scale based on multiples of 4px for visual rhythm and alignment.

<div style={{ display: "grid", gap: "16px", marginBottom: "32px" }}>
  {Object.entries(designTokens.spacing)
    .filter(
      ([key]) =>
        !key.includes("component") &&
        !key.includes("layout") &&
        !key.includes("container"),
    )
    .map(([name, value]) => (
      <div
        key={name}
        style={{ display: "flex", alignItems: "center", gap: "16px" }}
      >
        <div
          style={{
            minWidth: "60px",
            fontFamily: "monospace",
            fontSize: "14px",
          }}
        >
          {name}
        </div>
        <div
          style={{
            minWidth: "60px",
            fontFamily: "monospace",
            fontSize: "14px",
            opacity: 0.7,
          }}
        >
          {value}
        </div>
        <div
          style={{
            width: value,
            height: "24px",
            backgroundColor: designTokens.colors.primary[500],
            borderRadius: "2px",
          }}
        />
      </div>
    ))}
</div>

## Usage

Import design tokens in your components:

<Source
  language="typescript"
  code={`
import { designTokens } from '@/design';

// Use color tokens
const primaryColor = designTokens.colors.primary[500];

// Use spacing tokens
const padding = designTokens.spacing.md;

// Use typography tokens
const fontSize = designTokens.typography.fontSize.lg.desktop;

// Use motion tokens
const duration = designTokens.motion.duration.normal;
const easing = designTokens.motion.easing.easeOut;
`}
/>

## CSS Custom Properties

Design tokens are also available as CSS custom properties:

<Source
  language="css"
  code={`
/* Color tokens */
color: var(--color-primary-500);
background-color: var(--color-surface-900);

/_ Typography tokens _/
font-family: var(--font-family-sans);
font-size: var(--font-size-base);

/_ Spacing tokens _/
padding: var(--spacing-md);
margin: var(--spacing-lg);

/_ Motion tokens _/
transition: all var(--duration-normal) var(--easing-ease-out);

/_ Border radius tokens _/
border-radius: var(--radius-md);

/_ Shadow tokens _/
box-shadow: var(--shadow-md);
`}
/>
